# Excel Financial & Pricing Analysis

This folder contains the interactive Excel workbook developed for the
**AdventureWorks Sales Finance & Pricing Analytics** portfolio project.

## Interactive Excel Workbook

The workbook extends the SQL analysis into an interactive financial and
pricing analysis environment designed to support business decision-making.

### Analysis Included

- Project Overview
- Executive Dashboard
- Pricing Effectiveness Analysis
- Weekly Pricing Monitor
- Discount & Margin Model
- Performance Variance Analysis
- Price & Cost Sensitivity Model
- Pricing Execution Watchlist

### Excel Skills Demonstrated

- Power Query
- PivotTables and PivotCharts
- Interactive dashboards
- KPI analysis
- Pricing and profitability analysis
- Variance analysis
- Scenario and sensitivity analysis
- Business-focused data visualization
